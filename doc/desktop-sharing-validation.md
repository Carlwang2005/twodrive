# Development 桌面共享验证 / Desktop sharing validation

2026-10-15。新增服务端 GUI 位于 Development 桌面的“共享”，客户端入口位于“连接 → 添加连接 → 从 TwoDrive 连接文件添加”。CLI 服务保留；不是额外的独立服务端安装包。尚未发布新版 Release。

## 实现边界

- 一个桌面引擎拥有一个共享子进程，与活动存储连接独立；退出回收子进程。默认只读，必须显式选择目录。
- 私有配置目录不能被共享，连接文件不能写入共享目录或覆盖引擎私有状态。导出文件不包含本地共享路径、私钥或已授权设备状态；包含十分钟单次邀请秘密，不能公开上传。
- 原邀请格式继续兼容，增加 `connection` 公共提示。导入仅向界面返回名称、权限、文件路径和公钥；保存时沿用已有私有邀请复制与设备身份校验。
- 保存目录及选项，但启动应用不会自动开共享。相同目录与权限重用身份；改变目录或权限创建新身份，旧授权不会跟随到新范围。
- 默认网络策略保留直连优先与加密中继；“仅局域网”关闭公共中继。局域网发现为独立选项。这里没有引入公网 HTTP 监听或端口映射。

## 已执行验证

本机 Windows：Rust 测试及 release 引擎构建通过。新增导出测试检查无私有根路径、禁止静默覆盖、显式替换、旧邀请失效、单次授权和共享目录边界；导入测试检查公共提示、秘密不回传、错误设备和过期拒绝。共享身份测试检查配置目录边界、重命名保留身份及修改权限轮换身份。

`scripts/test-desktop-sharing.py` 运行两个隔离的真实 desktop 引擎和本机 QUIC 设备，验证启动/停止、导出/导入/配对、下载字节、上传字节、撤销后拒绝新请求、客户端断开不影响主机、显式替换重新授权、相同范围重启保留身份、修改权限轮换身份、只读拒写及停止后禁止导出。全部通过；不是两个物理网络的打洞测试。

Flutter 33 项测试通过，包括原设置/账号/更新回归及新增文件选择器交互。新增测试从主界面进入共享、选目录、只读启动、导出、停止；从添加连接导入、填入权限/名称、保存并连接新配置；取消文件选择保持原提供者。最小窗口 840×580 的导航和共享操作受到覆盖。文件选择器由平台接口测试替身驱动，不冒充真人操作系统对话框验收。

CI 已加入 Linux/Windows 的真实共享 IPC 烟测；最终 CI、原生 Windows release/MSIX 结果待补充。未验证实体 NAS、跨独立公网 NAT、签名 MSIX 安装或微软商店认证。本轮没有操作真实云账号。
