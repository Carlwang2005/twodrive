# TwoDrive CFAPI probe 0.1.7-alpha.1

An opt-in Windows native experiment with generated content. **Not a sync client,
installer, provider, account migration tool or Explorer acceptance claim.**

Run without arguments for a read-only CFAPI platform/capabilities query. The
registration scenario requires explicit host approval and a new disposable root.
Never use an existing OneDrive/Google Drive directory or cache. The scenario
retains its generated files and unregisters only the root it created.

Build, boundaries and truthful acceptance matrix:
[Windows CFAPI record](../../doc/windows-cfapi-2026-10-21.md).
